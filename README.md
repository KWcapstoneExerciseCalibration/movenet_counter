# MoveUP

소개: 집에서 운동을 할 때, 올바른 자세인지 판단하기 어렵다는 점과 동기 부여가 지속되기 어렵다는 점에 주목하여 만든 애플리케이션
기간: 2023년 4월 5일 → 2023년 9월 25일
인원: 4명

# Summary

## 핵심 기능

- 앱을 통해서 확인한 운동의 횟수와 점수, 소감과 난이도에 대해 저장 및 확인
- 운동 횟수와 자세의 정확도를 점수로 변환하여 계정의 레벨을 성장
    - 프로필과 코스의 난이도를 선택할 수 있도록 함
    - 운동 자세의 오류를 실시간으로 음성으로 피드백 함

## 개발 환경

- Android studio  - Kotlin
- Flutter
- Room DB

## 어려웠던 점

- z값이 있어야 벡터의 내적을 통해 신체 각도를 측정할 수 있었기 때문에 두 가지 방법을 생각했습니다.
    1. mono depth 모델을 가져와서 사용
        - Threading 방식을 사용해서 돌려 보았지만, 성능 저하가 발견되었습니다.
    2. 신체 길이를 기반으로 z값 생성
        - z = 0인 기준점 필요 : 발목을 기준으로 삼았습니다.
        - 모든 관절이 발목과 이어져 있지 않기 때문에, 연결된 관절의 위치를 차례차례 연산하였습니다.
- 화면에 비추는 사람의 크기는 항상 동일하지 않기 때문에 조정이 필요하다고 생각하였습니다.
    - 스쿼트와 숄더프레스의 경우, 어깨가 정면으로 보이는 방향에 카메라를 두고 운동을 하기 때문에 어깨를 기준으로 하였습니다. 팔굽혀펴기의 경우, 종아리가 가장 가리지 않고 안정적으로 촬영되기 때문에 종아리를 기준으로 삼았습니다.
    - 연산을 할 때는 저장되어 있던 비율과 현재 들어오는 영상을 기준으로 삼아 신체 길이를 갱신하여 사용하였습니다.
